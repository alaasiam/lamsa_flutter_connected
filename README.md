# لمسة — تطبيق Flutter لمتجر المكياج والعناية الطبيعية

تطبيق متجر Flutter مربوط بواجهة API الخاصة بمتجر لمسة على منصة سوقنا.

**رابط المتجر:** https://souqna.toldpath.com/api/v1/stores/lamsa

## التشغيل

1. افتحي المشروع في Android Studio أو VS Code مع Flutter SDK.
2. شغّلي `flutter pub get` لتثبيت الاعتمادات وتحديث `pubspec.lock`، خصوصًا `get_storage`.
3. شغّلي `flutter run`.

## الربط بلوحة التحكم

الإعدادات موجودة في `lib/api/api_settings.dart`، واسم المتجر `lamsa`. يحمّل التطبيق بيانات المتجر والهوية من `/stores/lamsa`، ومحتوى الرئيسية من `/stores/lamsa/home`، والمنتجات من `/stores/lamsa/products`. لذلك المنتجات والأسعار والصور والأقسام المعروضة يجب أن تكون منشورة في لوحة تحكم متجر لمسة؛ لا تُعرض معرّفات منتجات تجريبية في التطبيق.

يتطلب تسجيل الدخول والمفضلة والسلة وإتمام الطلب اتصالًا بالخادم وحساب عميل صالحًا. الدفع بالبطاقة في الشاشة الحالية موسوم كتجريبي؛ طريقة الدفع الفعلية المتاحة تعتمد على إعدادات الخادم.

## ملاحظات التطوير

- اللون والشعار والاسم ورقم الاتصال ورسوم التوصيل والحد الأدنى للطلب تُقرأ من إعدادات المتجر.
- ملفات `test/fixtures` تُستخدم لاختبار تنسيق نماذج الردود، وليست المنتجات الحية المعروضة داخل التطبيق.
- يلزم تشغيل `flutter pub get` ثم `flutter analyze` و`flutter test` على جهاز مجهّز بـ Flutter للتحقق النهائي من البيئة وبناء التطبيق.
